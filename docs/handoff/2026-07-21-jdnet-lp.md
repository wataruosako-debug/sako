## 3. 決定事項ログ
| 決定 | 理由 |
|---|---|
| CVは「無料相談・問い合わせ」 | 本人が選択。初回商談のゴール（セミナー誘導）より手前の相談を入口にする方針 |
| 料金プランは非掲載 | 本人が選択。目標・活動量で変動するため相談時に提示。FAQで「相談で提示」と受け皿を作った |
| 実績は全て匿名（業種＋数値） | 本人が選択。事例データに公開NG案件が多いため実名は使わない |
| 訴求の軸＝「当てずっぽうの営業を、当てにいく営業へ」 | 事例データで一貫する勝ち筋ロジック（成果が出ないのは商品でなく“当てる先”のズレ）が最も強い共通項だったため |
| デザイン: 濃紺×真鍮ゴールド／明朝見出し×グロテスク数字／照準（ターゲット）シグネチャ | 経営者向けの信頼感を出しつつ、AI生成に多い定番3パターン（クリーム×セリフ×テラコッタ等）を回避。明朝(経験)×数字(データ)の対比がJDネットの「20年の実績×AI」を体現 |
| 標準契約6ヶ月をFAQに明記 | 「ノウハウが資産化できる最短の区切り」という既存の正当化ロジックを踏襲 |
| フォームは会社名・氏名・メール・相談内容(任意)の4項目 | BtoBのCVR観点で項目最小化 |
