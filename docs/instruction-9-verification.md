# 指示書⑨ 実機確認チェックリスト(iPhone / iOS Safari)

対象: ジムタグ機能・ガイド中の履歴参照・日付変更(指示書⑨)
Playwright(chromium)では拾えない「ボタン位置の非移動・片手操作性・実データでの表示・iOS Safari固有の挙動」に絞った目視確認項目。
確認は本番URL https://wataruosako-debug.github.io/sako/ を**ハードリロード後**に行うこと(旧CSS/JSキャッシュ対策)。

チェック方法: 各項目の [ ] を実施後に [x] にする。NGは末尾「NGメモ」に画面名と症状を記録する。

---

## 1. レイアウト回帰(⑤⑥のロック維持)

- [ ] ガイドモードのセット記録画面に、進行カード内へ日付チップ(📅)・ジムチップ(📍)が表示されている
- [ ] **ボタン位置の非移動(⑥回帰)**: セット完了カードの「①この種目を続ける ②別の種目を行う ③メニューを終了」の
      3ボタンが、チップ追加前と同じ位置・同じ順番にある(セット中/完了カードを行き来しても動かない)
- [ ] **履歴パネル開閉でボタンが動かない(⑥回帰)**: 「この種目の記録（1ヶ月）」を開いても閉じても、
      その上にある完了ボタン群の位置が1pxも動かない(パネルは下方向にのみ開く)
- [ ] **パネル内スクロール(⑤回帰)**: 履歴が多いとき、パネル内でスクロールし、
      画面全体(ヘッダーやタブバー)は動かない。指を離すと元の位置に戻る
- [ ] ガイド画面全体が上下にスクロールしてズレない(アドレスバー表示中も含む)

## 2. 操作性(片手・親指圏)

- [ ] ジムチップをタップ → ジム選択シートが画面下部に出て、親指で届く位置に一覧＋「＋新しいジムを追加」がある
- [ ] ジム名入力(最大20文字)がiOSのキーボードで問題なく打てる。21文字目以降は入力できない
- [ ] 設定画面のジム管理: 「名前変更」「削除」ボタンが片手で押せるサイズ・間隔である
- [ ] 通常フロー記録画面の「ジム」行をタップ → 同じ選択シートが開く
- [ ] シートを開いたまま端末を片手で持ち替えても、誤タップしにくい配置になっている

## 3. 他ジム記録の視覚的区別

- [ ] ガイドの履歴パネルで、現在のジムの記録が上に、他ジムの記録が下に並んでいる
- [ ] 他ジムの記録が**淡色**で表示され、ジム名の横に「参考」が付いて、現在ジムの記録と区別できる
- [ ] 現在のジムでの記録が1ヶ月以内に無いとき、「このジムでの記録はありません」が表示され、
      その下に他ジムの記録が(淡色で)並ぶ
- [ ] 種目を切り替えると履歴パネルが閉じた状態に戻る(別種目の記録と混ざらない)

## 4. 実データでの確認(移行結果)

- [ ] **既存記録が全て「マイジム」になっている**: 過去の任意の日をカレンダーから開き、
      セッションに「📍マイジム」が表示されている(移行漏れがない)
- [ ] 設定 → ジム で「マイジム」がリネームできる。リネーム後、過去記録の表示名も新名称に変わる
- [ ] **8/16の別ジムの記録をカレンダーから開く**: 日別詳細でセッションの「ジム変更」ボタンを押し、
      別ジム(または新規追加したジム)に変更できる。変更後、日別詳細とホームに反映される
- [ ] 新しいジムを追加し、そのジムで新規記録 → 別ジムの前回重量がプリフィルされない(空 or そのジムの前回)ことを体感で確認
- [ ] 同じジムで2回目以降の記録 → 前回重量がプリフィルされ、条件を満たせば重量提案が出る

## 5. 成長グラフ・自己ベスト

- [ ] 成長画面にジム切替(「すべて」＋各ジム)が出る。ジムを切り替えると線が変わる
- [ ] グラフのジム選択がアプリ再起動後も維持されている
- [ ] 自己ベスト達成バナー・成長の自己ベスト欄に、達成したジム名が併記されている(例: ○○kg（Bジム）)

## 6. 日付変更

- [ ] ガイド進行中に日付チップをタップ → 日付変更モーダルが開く。カレンダーで**未来日は選べない/弾かれる**
- [ ] 既に記録がある日付に変更しようとすると「その日には既に記録があります」で弾かれる
- [ ] 空いている過去日に変更 → 「○月○日 → ○月○日 に変更しますか？…」の確認後、
      **セッション全体(全種目・全セット・有酸素)が一緒に移動**する
- [ ] 日付変更後、保存してカレンダーを見ると、記録が移動先の日付に付いている(元の日には無い)
- [ ] 移動先の月の月次カロリー・日数に反映されている
