# 指示書⑦ 実機確認チェックリスト(iPhone / iOS Safari)

対象: カロリー計算の種目別化(PR #11 / main `4ee05f4`)
Playwright(chromium)では検出できない「iOS Safari固有のレンダリング・実データでの表示値・片手操作性」に絞った目視確認項目。
確認は本番URL https://wataruosako-debug.github.io/sako/ を**ハードリロード後**に行うこと(旧CSS/JSキャッシュ対策)。

チェック方法: 各項目の [ ] を実施後に [x] にする。NGの場合は末尾の「NGメモ」に画面名と症状を書く。

---

## 1. 有酸素の入力UI

### 通常フロー(記録 → ジム/自宅 → 有酸素種目を選択)
- [ ] **バイク**を選ぶ → 入力欄が「時間・距離・**平均ワット**・メモ」になり、**傾斜欄が消えている**
- [ ] **ウォーキング**を選ぶ → 従来どおり「時間・距離・**傾斜**・メモ」で、ワット欄は出ない
- [ ] **クロストレーナー**を選ぶ → 傾斜欄もワット欄も**両方出ない**(時間・距離・メモのみ)
- [ ] **階段**を選ぶ → 同上(傾斜・ワットとも非表示)
- [ ] バイクで時間30分だけ入れてW未入力のままにする → プレビューに
      「**カロリー未算出(Wを入力すると計算されます)**」と表示される(kcal数字が出ない)
- [ ] バイクでWを入力(例: 90) → プレビューに kcal が表示される(90W×30分なら約198kcal)
- [ ] バイクでW・時間・距離を入力した状態から種目を**ウォーキングに切り替えて保存** →
      保存された記録にワット値が残っていない(保存後の記録詳細にワット表記がない)。
      逆にウォーキングで傾斜を入れてから**バイクに切り替えて保存** → 傾斜が保存されていない
- [ ] ワット欄の「−」「＋」ボタン(±5W)が**片手の親指で押しやすい**
      (他の±ボタンと同等のサイズ・間隔で、指示書③のボタンサイズから外れていない)
- [ ] ワット欄をタップしたときに**数字キーボード**が出る(フルキーボードにならない)

### ガイドモード(ガイドで有酸素種目に到達)
- [ ] バイクのガイド画面 → 傾斜欄が消え、平均ワット欄が表示されている
- [ ] バイクでW未入力 → ガイドのプレビューにも「カロリー未算出(Wを入力すると計算されます)」
- [ ] クロストレーナー/階段のガイド画面 → 傾斜・ワットとも非表示
- [ ] ウォーキングのガイド画面 → 傾斜欄が従来どおり表示される

## 2. レイアウト(iOS Safari固有・指示書⑤の回帰確認)

- [ ] ホーム画面: 概算消費カロリーカードの下に「**カロリーは目安です**」が1行で表示され、
      カードからはみ出したり折り返しで崩れたりしていない
- [ ] ホーム画面: **アドレスバーが表示されている状態でも**上下にスクロールできない
      (指で引っ張ってもカレンダーがズレず、指を離すと必ず元の位置)
- [ ] ホーム画面: カレンダーとタブバーの間の隙間が以前と同程度(広告1枠分)で、過剰な余白がない
- [ ] トレーニング保存後の完了サマリーモーダル: 統計の下の「カロリーは目安です」が
      モーダルの幅内に収まり、ボタン等と重なっていない
- [ ] 有酸素入力でワット欄が表示/非表示に切り替わる瞬間に、画面がガタつかない・
      下のボタンが押している最中に移動しない

## 3. 実データでの表示値

- [ ] **過去の月次カロリー据え置き**: ホームで先月(記録がある月)に切り替え、
      概算消費カロリーの数値がアップデート前にメモしていた値と**同じ**であること
      (事前にアップデート前の値を控えておくのが理想。不明な場合は「極端に変わっていない」ことを確認)
- [ ] **成長グラフ据え置き**: 成長 → 全体タブ → 総消費カロリー。過去の日付のポイントが
      以前のグラフと同じ形状のまま(過去分が一斉に増減していない)
- [ ] **バイクの実測比較**: ジムのバイクで表示された平均W・時間・消費kcalをメモし、
      同じW・時間で記録 → アプリのkcalがマシン表示と近い(±10%目安)
- [ ] **筋トレの種目差**: 同じ日にデッドリフト(高重量・コンパウンド)とアームカール(低重量・単関節)を
      記録し、完了サマリーや日別表示でデッドリフト側が明確に大きいこと
      (体感の目安: DL 100kg×10×4 ≒ アームカール 15kg×12×3 の3〜4倍)
- [ ] 新規保存したセッションの合計カロリーが、ホーム月次にも即時反映される
