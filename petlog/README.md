# うちのこ日誌（仮）

シニア期（目安7歳〜）の犬・猫の飼い主向け、「1日3秒、タップだけ」の健康記録アプリ MVP。
「毎日続く最小記録」に特化し、ホームの **「今日もぜんぶ順調」を1タップ**で記録が完了します。

## 技術方針

- `index.html` / `style.css` / `script.js` の **3ファイルのみ**。ビルド無し。
- データは **localStorage** に保存（サーバー送信なし）。JSはES5スタイル・単一IIFE。
- デザイントークン・データ層・トースト/Undo・±長押し・カレンダー描画などは
  ジムログ（本リポジトリ root）のパターンを部品単位で流用し、テーマカラーを暖色系に差し替え。
- CSS/JS変更時は `index.html` の `?v=` クエリを更新すること。

> 本来は独立リポジトリでの公開（GitHub Pages）を想定。現状はジムログを流用元として
> 参照するため、同リポジトリ内の `petlog/` に配置しています。

## 主な機能（MVP）

1. ペット登録（複数対応）と切り替え
2. ホーム＝今日のチェックリスト＋「今日もぜんぶ順調」ワンタップ記録
3. 過去日の記録・編集（ミニカレンダー日付タップ）
4. 体重記録＋推移グラフ（期間切替）
5. お薬マスタ登録＋毎日のチェック連動
6. 異変アラート（3ルール：ごはん2日連続の食べ残し／うんち2日連続なし／体重-5%減）
7. 獣医レポート（直近14日）
8. 設定（テーマ／バックアップ・復元／全削除）

## ローカル起動

```
npx http-server . -p 8080   # もしくは任意の静的サーバー
# → http://localhost:8080/index.html
```

## テスト

ジムログと同じ Playwright + ローカルHTTPサーバー方式。

```
cd tests
PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers node e2e.mjs
```

`window.__PETLOG_TEST_MODE = true` で `window.__test`（getData/setData/setToday/
tapChecklist/getAlerts など）を公開します。日付依存ロジック（2日連続判定・7日経過バッジ）は
`__test.setToday()` で日付を注入して検証します。
