# ノビログ

ノビログは、初心者でもすばやく記録できるスマホ向け筋トレ管理WEBアプリです。
ジム・自宅での筋トレと有酸素運動を記録し、カレンダーと概算消費カロリーで毎日の頑張りを確認できます。

## 起動方法

1. アプリのフォルダを開きます。
2. `index.html` をダブルクリックします。
3. ブラウザでノビログが開きます。

インストールやコマンド操作は必要ありません。

## 主な機能

- 今月のジム回数と概算消費カロリーを表示
- ジムの日を青、自宅トレーニングの日を緑でカレンダー表示
- 日付ごとの筋トレ・有酸素運動のサマリー表示
- プロフィール（体重、身長、年齢、性別）の保存
- 種目検索、お気に入り、新しい種目の追加
- 胸・肩・腕・背中・脚・腹などの横並びタブから種目を選択
- カテゴリ別の重量刻み幅
- 回数、あと何回できそうか、インターバル、メモの記録
- 保存したセットの重量・回数・インターバルを次セットへ自動コピー
- 保存済みセットをタップして重量・回数・休憩などを直接編集
- 有酸素運動の速度と概算消費カロリーの自動計算
- 過去記録の再利用、編集、削除
- 種目ごとの初回・最新・伸び幅・自己ベストを表示
- 筋トレと有酸素運動の成長を折れ線グラフで確認

## データ保存方式

プロフィールと記録は、ブラウザの `localStorage` に保存されます。
外部サーバーへの送信はありません。

## 注意点

- ブラウザを変えるとデータは引き継がれません。
- ブラウザの閲覧データやキャッシュを削除すると、記録が消える場合があります。
- スマートフォンとパソコンの間でデータは同期されません。
- 消費カロリーは入力内容をもとにした概算値です。
- プライベートブラウズでは保存内容が終了時に消える場合があります。
